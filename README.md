# Student Placement Prediction System

A full-stack Machine Learning web application that predicts a student's
placement probability based on academic performance, technical skills,
internships, projects, communication, aptitude, coding ability, attendance,
and extracurricular activities.

---

## Features

- Clean, modern SaaS-style dashboard UI (React + Tailwind CSS)
- Multi-section student input form with live validation, tooltips, and a
  completion progress bar
- Selectable technical-skills chips (converted into model features)
- Random Forest ML model served via a FastAPI backend
- Placement probability shown as a percentage (not raw 0/1), with a circular
  gauge and donut chart breakdown
- Radar chart profile analysis (CGPA, coding, aptitude, communication,
  attendance, projects)
- Rule-based improvement recommendations (separate from the ML prediction)
- "What Influenced Your Prediction?" section using Random Forest feature
  importance
- Dashboard with aggregate statistics and 5 Recharts visualizations
- Recent Predictions table (local/mock state, structured for an easy future
  database swap)
- Friendly error handling — no raw stack traces are ever shown to the user
- Fully responsive (desktop, tablet, mobile)

## Tech Stack

**Frontend:** React (Vite), JavaScript, Tailwind CSS, Axios, React Router,
Recharts, Lucide React

**Backend:** Python, FastAPI, Pydantic, Uvicorn, Pandas, NumPy, Scikit-learn,
Joblib

**ML Algorithm:** Random Forest Classifier
(`n_estimators=200, class_weight="balanced", random_state=42`)

## Dataset

`backend/data/students.csv` — 900 synthetically generated student records.
Generated by `backend/generate_dataset.py`, seeded from realistic statistical
distributions (informed by an example real-world-shaped dataset) and a
hand-designed logistic placement-probability function with added noise, so
the classification problem is realistic rather than trivially separable.

Columns: `student_id`, `cgpa`, `tenth_percentage`, `twelfth_percentage`,
`backlogs`, `internships`, `certifications`, 14 individual skill columns
(`python_skill`, `java_skill`, `cpp_skill`, `javascript_skill`, `react_skill`,
`sql_skill`, `machine_learning_skill`, `data_science_skill`, `django_skill`,
`fastapi_skill`, `nodejs_skill`, `git_skill`, `aws_skill`, `docker_skill`),
`communication_score`, `aptitude_score`, `projects`, `coding_score`,
`attendance`, `extracurricular`, `placed` (target).

No post-outcome features (offer received, company, package, etc.) are
included — every feature represents information available **before**
a placement decision, to avoid data leakage.

## Installation

### Backend

```bash
cd backend
python -m venv venv
```

Activate the virtual environment:

Windows:
```bash
venv\Scripts\activate
```

macOS / Linux:
```bash
source venv/bin/activate
```

Install dependencies:
```bash
pip install -r requirements.txt
```

(Optional) Copy the env example and adjust if needed:
```bash
cp .env.example .env
```

The dataset and trained model are already included in this zip
(`data/students.csv`, `model/placement_model.pkl`,
`model/feature_config.pkl`). To regenerate them from scratch instead:

```bash
python generate_dataset.py
python train_model.py
```

Run the API server:
```bash
uvicorn app.main:app --reload
```

The API will be available at `http://localhost:8000`.

### Frontend

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

The app will be available at `http://localhost:5173`.

## Testing Instructions

1. Start the backend (`uvicorn app.main:app --reload`) and confirm
   `http://localhost:8000/api/health` returns `{"status":"ok","model_loaded":true}`.
2. Open `http://localhost:8000/docs` and try `POST /api/predict` with the
   example payload above.
3. Start the frontend (`npm run dev`) and open `http://localhost:5173`.
4. Go to **Predict**, fill out the form (try an out-of-range value like
   CGPA `15` to confirm validation blocks it), and submit.
5. Confirm the result card, radar chart, feature importance, and
   recommendations all render.
6. Visit **Dashboard** and confirm stats/charts load from the backend.
7. Stop the backend and reload the Predict page — confirm the frontend shows
   a friendly "Unable to connect to the prediction server" message rather
   than a crash or stack trace.

## Deployment Instructions

**Backend:** Deploy the FastAPI app (e.g. on Render, Railway, Fly.io, or a
VM) using `uvicorn app.main:app --host 0.0.0.0 --port $PORT`. Set the
`FRONTEND_URL` environment variable to your deployed frontend's URL so CORS
allows it.

**Frontend:** Build with `npm run build` (outputs to `frontend/dist/`) and
deploy the static files (e.g. on Vercel, Netlify, or any static host). Set
`VITE_API_URL` to your deployed backend's URL before building.

Never hard-code production URLs — both are read from environment variables
(`FRONTEND_URL` on the backend, `VITE_API_URL` on the frontend).

## How the Random Forest Prediction Works

1. The frontend sends the student's raw form data (including selected
   skill labels) as JSON to `POST /api/predict`.
2. FastAPI validates the payload against the `StudentData` Pydantic schema
   (range checks, type checks, allowed-skill checks).
3. `preprocessing.py` converts the selected skill labels into 14 binary
   features and assembles a single-row feature vector in the **exact**
   column order stored in `feature_config.pkl` (generated during training,
   so training and inference can never drift out of sync).
4. The trained `RandomForestClassifier` (an ensemble of 200 decision
   trees) votes on the outcome. `predict_proba()` returns the fraction of
   trees that voted "placed," which is reported as the placement
   probability percentage.
5. Separately, `recommendation_service.py` applies simple rule-based
   thresholds (e.g. coding score < 60) to generate improvement tips — this
   logic does not influence the ML prediction itself.
6. The model's global `feature_importances_` (from training) are surfaced
   as "What Influenced Your Prediction?" — these describe which factors
   matter most across the whole model, not a causal explanation of this one
   prediction.

## Common Errors & Solutions

| Error | Cause | Solution |
|---|---|---|
| `Unable to connect to the prediction server` | Backend not running or wrong `VITE_API_URL` | Start the backend and verify the `.env` URL matches |
| `503 Prediction model is not available` | `model/placement_model.pkl` missing | Run `python train_model.py` in `backend/` |
| CORS error in browser console | `FRONTEND_URL` on backend doesn't match frontend origin | Update `backend/.env` `FRONTEND_URL` to match, restart backend |
| `pip install` fails on scikit-learn | Missing build tools / old pip | `pip install --upgrade pip` then retry |
| Blank page on `npm run dev` | Dependencies not installed | Run `npm install` inside `frontend/` |
| 422 Unprocessable Entity from `/api/predict` | Input outside allowed range or invalid skill name | Check the field ranges in the API docs (`/docs`) |
